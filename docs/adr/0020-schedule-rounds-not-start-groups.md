# Schedule Rounds, not Start Groups

The public timetable and competition operations assign a scheduled time to each Round. Start Groups such as heats and flights run sequentially from that Round time and do not have independent scheduled times. A qualifying Round and a final are separate Rounds, so each may have its own time. Selecting a Start Group changes the entries and results in view without implying a second timetable entry. This keeps the published schedule aligned with how organizers advertise consecutive heats while preserving exact Start Group result data.
